# Project Notes

*   **Goal:** Create a <20GB ZIM file from public domain texts, PDFs, and audiobooks about the GSMNP and DuPont State Park regions.
*   **Methodology:**
    1. Python scraper (`scrape_and_zimit.py`) to download content and generate `index.html`.
    2. Zimit to package local files into `Appalachian_Corridor.zim`.
